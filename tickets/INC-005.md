## 1. Issue Description
Operations department print jobs stuck in queue with status 'Error - Printing'.

## 2. Root Cause Analysis (RCA)
Corrupt print job payload stalled the Windows Print Spooler service (spoolsv.exe).

## 3. Resolution Steps
Stopped Spooler service, purged corrupt .SPL files from C:\Windows\System32\spool\PRINTERS, and restarted service.

## 4. Verification & Prevention
- **Verification:** Printed Windows test page successfully; subsequent queued shift manifest printed without error.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
