## 1. Issue Description
Workstation not applying corporate security baseline GPO; screen lock timeout policy failing.

## 2. Root Cause Analysis (RCA)
Workstation joined domain into default CN=Computers container rather than targeted OU=Workstations.

## 3. Resolution Steps
Moved computer object to OU=Workstations,OU=Computers,OU=NorthStar on DC, and ran gpupdate /force on client.

## 4. Verification & Prevention
- **Verification:** gpresult /r confirmed GPO-Workstation-Baseline applied; screen automatically locked at 10 minutes.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
