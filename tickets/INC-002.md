## 1. Issue Description
User unable to log into Windows 11 workstation; receives 'The referenced account is currently locked out'.

## 2. Root Cause Analysis (RCA)
User entered expired password 5 consecutive times, exceeding the GPO baseline lockout threshold.

## 3. Resolution Steps
Executed Unlock-ADAccount -Identity jsmith and set temporary password with mandatory change at logon.

## 4. Verification & Prevention
- **Verification:** User successfully authenticated to NS-PC01 and rotated password to new compliant string.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
