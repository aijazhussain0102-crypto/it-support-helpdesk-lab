## 1. Issue Description
User receives 'Access Denied' error when attempting to open network directory \\NS-FS01\Finance.

## 2. Root Cause Analysis (RCA)
Working as designed under Principle of Least Privilege. User is member of GG-Sales and lacks GG-Finance-Share group.

## 3. Resolution Steps
Educated user regarding departmental boundaries and mapped the correct sales share (\\NS-FS01\Sales).

## 4. Verification & Prevention
- **Verification:** User confirmed full read/write access to Sales share while Finance share remained securely restricted.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
