## 1. Issue Description
Workstation reports 'No Internet Access'; cannot open corporate email or web portals.

## 2. Root Cause Analysis (RCA)
Statically assigned invalid default gateway (10.10.20.1) prevented off-subnet packet routing.

## 3. Resolution Steps
Reconfigured network adapter IPv4 properties to obtain IP via DHCP and renewed lease with ipconfig /renew.

## 4. Verification & Prevention
- **Verification:** Pings to default gateway (10.10.10.1) and web DNS (google.com) succeeded immediately.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
