## 1. Issue Description
User unable to install approved PDF utility; blocked by User Account Control (UAC) administrator prompt.

## 2. Root Cause Analysis (RCA)
Standard corporate user lacks local administrative rights (Principle of Least Privilege).

## 3. Resolution Steps
IT technician deployed the approved application remotely using silent administrative command msiexec /i /qn.

## 4. Verification & Prevention
- **Verification:** Application shortcut appeared on desktop; user opened sample contract PDF successfully.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
