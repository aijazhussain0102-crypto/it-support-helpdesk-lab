## 1. Issue Description
Workstation can ping 8.8.8.8, but cannot resolve internal domain northstar.local or corporate file shares.

## 2. Root Cause Analysis (RCA)
Workstation adapter DNS was manually pointed to public resolver 8.8.8.8 which has no record of the private AD zone.

## 3. Resolution Steps
Repointed primary DNS to NS-DC01 (10.10.10.4) and executed ipconfig /flushdns and ipconfig /registerdns.

## 4. Verification & Prevention
- **Verification:** nslookup northstar.local resolved to 10.10.10.4; SMB file shares opened immediately.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
