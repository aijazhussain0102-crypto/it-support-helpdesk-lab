## 1. Issue Description
User account repeatedly locks out every 15 minutes without user touching keyboard.

## 2. Root Cause Analysis (RCA)
Stale cached domain credentials in Windows Credential Manager from previous password change attempted background SMB auth.

## 3. Resolution Steps
Inspected Event ID 4740 on DC to identify caller PC, cleared stale credentials in Credential Manager, and cleared net use sessions.

## 4. Verification & Prevention
- **Verification:** Monitored DC Security log for 45 minutes; zero subsequent lockout events occurred.
- **Prevention:** Enforce standardized Group Policy baselines, automated monitoring scripts, and least-privilege role separation.
